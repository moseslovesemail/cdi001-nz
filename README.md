## Data integrity

- Building consents are presented as development/construction-intent signals, not proof construction has started.
- Resource-consent stages must remain distinct.
- Public sample records must be traceable to their council source.
- Applicant/owner natural-person names are not core V1 commercial fields.
- Illustrative examples must always be explicitly labelled and kept separate from verified records.
